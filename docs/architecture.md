## 技术栈

- **前端**: Vue 3 + Vite + TypeScript + Rust-WASM
- **后端**: Node.js 18+ + Express + gRPC
- **AI服务**: Python 3.10+ + Flask + BERT
- **高性能服务**: Rust 1.70+ + Actix-web + gRPC
- **数据库**: MySQL 8.0

## 服务通信

- 前端 ↔ Node后端: HTTP/WebSocket
- 前端 ↔ WASM: 直接调用
- Node ↔ Python: gRPC (端口50051)
- Node ↔ Rust: gRPC (端口50052)

## 部署环境

纯Windows 10/11本地环境，禁用Docker容器化。

## 加密算法说明

平台 Rust 高性能服务 `crypto.rs` 中实现两套加密算法：

| 角色 | 算法 | 用途 |
|------|------|------|
| 生产主算法 | AES-256-GCM | FaceGuard 人脸特征向量加密、HMAC 防篡改 |
| 自研对照算法 | FEN-SAFE v1.1 | 移动端低算力场景备选方案、教学/科研输出 |

**FEN-SAFE v1.1** 是自研 128bit 分组 / 128bit 密钥轻量分组密码（LIGHT 5 轮 + SECURE 7 轮双版本），与 AES-128 在同等无硬件加速环境下对照测试，完整权威测试报告（SAC 雪崩、S 盒指标、MixSegments 扩散层、差分/线性安全、NIST SP800-22 随机性、KAT、性能对标）见 [加密算法_权威测试报告.md](./加密算法_权威测试报告.md)。

主要测试结果：

- SAC 雪崩：LIGHT 64.00bit / SECURE 64.04bit（理论最优）
- FEN-SBOX-256 S 盒：DDT=4（与 AES/SM4 同级）、非线性度 112（达 AES 同级）
- NIST SP800-22 随机性：11/11 全 PASS
- KAT 加解密正确性：1000/1000 通过
- 性能（ARM A55 Java 无硬件加速）：LIGHT 2μs/分组，快于 AES-128 软件基准

**综合安全等级评估：商用安全级**
